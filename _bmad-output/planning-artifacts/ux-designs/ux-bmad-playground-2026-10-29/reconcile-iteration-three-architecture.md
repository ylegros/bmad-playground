# Adopted iteration-three architecture — UX input reconciliation

Source: [ARCHITECTURE-SPINE.md](../../architecture/architecture-bmad-playground-2026-10-29/ARCHITECTURE-SPINE.md), adopted by the iteration-three spec. This reconciliation records the architecture rules the UX must carry; it does not establish implementation, audited coverage, asset acquisition or publication.

## Load-bearing UX rules

| Architecture input | Required UX contract |
| --- | --- |
| AD-11 / CAP-1: constructor identity | Every constructor identity has exactly one accessible team-name label across surfaces and controls. Valid historical logos are decorative beside that name. Missing or failed logos remove the image/frame and introduce no text-filled fallback badge or second team-name label. Driver failures retain initials in portrait frames. |
| AD-8/11: imagery across the expanded range | Target every audited driver/season and constructor/season slot for 2010–2026 with verified photographs and historically suitable logos, local files and credits. Disclose photograph date or unknown. Reused files may cover applicable seasons; investigated fallbacks remain separate from mapped-image counts. Remaining exceptions require individual evidence and user acceptance. |
| AD-8/13 / CAP-2: verified season choices | The candidate range is all 17 years, 2010–2026. Enable analysis only for individually verified years; expose pending/failed audits and honest availability rather than treating a larger dropdown as support. Default to the latest verified supported year, including audited ongoing years. The UI never starts a background 17-year download. |
| AD-13: lifecycle and availability | Keep held, unheld, cancelled and unknown lifecycle distinct from availability. Unheld displays **Not held**, cancelled **Cancelled**, a verified non-sprint **Not applicable**, and held missing records **Unavailable**. Unknown lifecycle is an unresolved audit gap and prevents verification. Empty responses alone never establish lifecycle or zero points. |
| AD-3/10/13: one analysis window | All analysis uses independently verified held GP rounds, including held rounds with source gaps. Exclude unheld/cancelled GPs from completed-GP comparisons, while retaining the full calendar in charts/tables with explicit states. Ongoing 2026 stays **Ongoing / Season to date** with explicit analyzed rounds and samples until completion is independently verified. Authoritative qualifying/sprint results before an unheld GP may appear with their exclusion from completed-GP comparisons explained. |
| AD-3/10/13: comparison and standings honesty | Keep all six equal-vote comparison categories and their tie/unavailable rules. Best finish/qualifying and DNF counts need conservative driver evidence throughout the same window; unheld rounds do not cause missing-data failures, held gaps still do. Zero completed GPs makes GP-based categories unavailable. Official standings use their own source round, disclose lag behind the analysis window, say **Current standings** until verified completion, and never extrapolate totals. |
| AD-2/10/13: chart and evidence agreement | Charts and semantic tables share selectors, chronological rounds, GP/sprint separation, zero/missing distinctions and explicit unavailable reasons. Preserve calendar states, chart gaps, rank 1 at the top, stable named styles, keyboard/pointer inspection and readable narrow/zoomed layouts; never draw through unavailable sessions or fabricate future points. |
| AD-6/14 / CAP-3: search and bulk selection | Search only filters the active season/category list with the existing case-insensitive name-substring predicate. **Select all** unions the selection with all matches in the complete list, including offscreen entries. Empty search matches all, no matches is a no-op, repeats are idempotent and selected nonmatches remain selected. |
| AD-14: clear/remove and URL history | **Clear selection** removes every active-category selection, including hidden nonmatches; remove-one removes exactly one ID. One effective selection action makes one history update; no-op actions make none. Driver and constructor sets remain separate, with deterministic `graphDrivers` / `graphConstructors` URL serialization and Back restoring the same state everywhere. |
| AD-14: context changes and empty state | Validate decoded IDs against the loaded season/category, preserve valid IDs and remove invalid ones only. On year change, clear legacy `entity` and comparison A/B, retain each graph set only where valid, and announce discarded IDs before rendering. Explicit graph keys take precedence over legacy links. Empty selection removes both the active graph key and legacy `entity`; neither key means an empty set, never automatic default selection. Pending actions cannot commit into another season/category/snapshot. |
| AD-14: every selected series remains usable | Chart, evidence table, selected controls and URL share one uncapped selection set. Search does not hide selected series from chart/table. Virtualization may optimize rendering without dropping entities; every selected series remains distinguishable and inspectable, including narrow widths and 200% zoom with intended scrolling. Native keyboard-operable actions announce resulting selection. |
| AD-5/9/13: freshness and retained data | Show the selected season's source timestamp and explicit local timezone; export time is separate. Local successful refresh commits data and matching lifecycle/window/freshness metadata together. Failed refresh preserves both data and metadata. Ignore obsolete requests. Bundled mode has immutable static reads, static retry and no runtime provider/API fallback; local refresh changes hosted data only through a new validated release. |
| AD-10/12: preserved accepted behavior | Preserve qualifying before grid penalties, visible favorable tick/highlight with accessible driver/metric/direction text, no repeated visible Better label, no favorable marker for ties/unavailable, local explicit refresh and existing anyone-with-link hosted audience. Document alignment authorizes no rebuild or publication. |
